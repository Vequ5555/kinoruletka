# Director’s Roulette 2.0 — разработка

Android-проект персонального киноквеста. Это незавершённая версия: перед использованием для прохождения см. ограничения ниже.

## Сборка

Требуются JDK 17 и Android SDK с platform 35 и build-tools 35.0.0. Выполните из корня проекта:

```sh
node --test tests/*.test.js
./gradlew assembleDebug
```

Результат — `app/build/outputs/apk/debug/app-debug.apk`. Debug APK подписывается стандартным отладочным ключом; он предназначен для тестирования, а не для гарантированных обновлений между независимыми сборками.

## GitHub Actions

Workflow `Android debug APK` запускается вручную в разделе Actions через Run workflow, а также при обновлении `main` и в pull request. После успешного запуска откройте его страницу и скачайте архив `directors-roulette-debug` в разделе Artifacts. Распакуйте APK на телефоне и откройте его; Android может попросить разрешить установку из выбранного источника. Доступность скачивания зависит от доступа к репозиторию и настроек GitHub.

## Данные

Приложение хранит состояние локально в WebView с постоянным origin. В настройках доступны экспорт и импорт JSON через системный выбор файлов; перед импортом показывается подтверждение. Сохранения версии 1.0 несовместимы с новыми правилами оценивания. Для переноса или перед удалением приложения экспортируйте копию. Удаление приложения удаляет локальные данные.

## Текущее состояние и ограничения

Реализованы список из 25 режиссёров и 150 фильмов по заданию, сохранение результата розыгрыша до анимации, блокировка повторного выбора, одна случайная замена, оценки, коллекция, базовая статистика, импорт и экспорт. Модель проверяется тестами Node.js.

Проект ещё не соответствует полному заданию: подробные карточки фильмов, точные продолжительности, полная статистика и часть достижений пока отсутствуют. Данные о режиссёрах и краткие аннотации частично перенесены из версии 1.0 и требуют проверки. На колесе есть 25 пронумерованных секторов и список соответствующих имён; геометрия проверена тестом. Щелчки сопровождают прохождение секторов, тактильный отклик срабатывает при остановке. Не проверены запуск на Android, импорт и экспорт на устройстве, визуальная доступность и обновление приложения. Debug APK для коммита 296bb2e собран в GitHub Actions; установка и запуск на устройстве ещё не проверены. Исходная веб-версия находится в `directors_roulette/`.
