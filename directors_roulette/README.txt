DIRECTOR'S ROULETTE — версия 1.0

ЗАПУСК НА ANDROID:
1. Самый простой вариант: откройте index.html в браузере Android через файловый менеджер. Колесо, карточки и прогресс работают без интернета, но установка в качестве PWA и резервный режим service worker при file:// недоступны.
2. Для полноценной установки как приложения (PWA) загрузите папку целиком на любой HTTPS-хостинг, например GitHub Pages / свой хостинг, откройте ссылку в Chrome Android, используйте меню ⋮ → «Установить приложение» / «Добавить на главный экран». После первого посещения базовые функции работают офлайн.
3. Для локального тестирования на ПК: откройте терминал в папке и выполните python -m http.server 8080, затем перейдите на http://localhost:8080.

ПРАВИЛА:
- Ровно 25 секторов; прокрутка 10 секунд.
- Случайный выбор только из ещё не завершённых режиссёров.
- Три фильма обязательны. Разблокировка следующего розыгрыша только после отметки всех трёх и явного завершения текущего режиссёра.
- Прогресс, история и выбор сохраняются локально в localStorage.
- Кнопки экспорта и импорта JSON помогают перенести прогресс на другой браузер/устройство.
- Биографии встроены и не требуют сети; ссылка на русскую Википедию открывается отдельно.
- Пункт «Сбросить весь прогресс» требует двойного подтверждения.

ОГРАНИЧЕНИЯ:
- Это автономное веб-приложение, а не APK. Для установки PWA нужен HTTPS-сайт (или localhost).
- При открытии через file:// некоторые браузеры ограничивают localStorage; используйте экспорт сохранений и предпочтительно PWA.
- Фильмография — авторская подборка, не официальный канон. Описания — краткие редакционные резюме, не дословные статьи Википедии.
